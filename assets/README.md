# Assets (not in git)

All heavy assets live outside git, in the directory `$OMUZAKI_ASSETS/` (default: `assets-local/` in the workspace root, which is git-ignored):

- `characters/<name>/{concept,blender,export,renders}`: per-character sources and outputs
- `datasets/`: training and synthetic data (for example `datasets/synthface/`, with licence notes in `datasets/synthface/LICENSES.md`)
