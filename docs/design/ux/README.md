# UX direction

The design brief: "an amazing, easy-to-use interface for both agents and humans". This folder sets the direction for the `omuzaki-ui` desktop app (spec v3, phase 1: viewport, part tree, inspector, command palette, history) before anyone builds panels.

## Read in this order

| File | What it settles | Read it when |
|---|---|---|
| `principles.md` | twelve UX principles (P1 to P12), each with "so we do" and a check, plus what the UI owes agents and a panel definition of done | before designing any screen; reviewers cite it by number |
| `shell.md` | the layout of the app: regions, workspaces, docking, viewport, outliner, inspector, command palette, History, Agent panel, Build Theatre, Perform, empty states, first-run flow, keyboard map | before building a panel or the shell |
| `design-system.md` | tokens (colour with contrast ratios, type, spacing), icons, motion, component specs, the egui mapping, UI performance rules, tests | before building a widget |
| `wireframes/` | six SVG screens at 1920×1080 and 1366×768, generated by `scenes.py` | open at full size; callout numbers match the legends in `shell.md` |

## The direction in six lines

1. **One document, many hands.** People and agents are peers over the same ops; the UI always shows who did what and why (P1).
2. **See it change.** Every edit previews live, in the viewport, before it commits (P2). Everything is undoable on one honest timeline (P3).
3. **The Build Theatre is the signature screen.** Agent work is visible, followable, steerable and budgeted (P4).
4. **Few decisions, revealed gradually.** Essentials first, advanced on demand, never a Simple/Pro switch (P5, P6).
5. **Keyboard and palette parity with MCP.** Ctrl+K reaches every op, with a form generated from the same schema agents use (P8).
6. **A quiet, dark, warm editor.** Gold for you, violet for agents, status by icon and word, 60 fps, idle at zero cost (P12).

## Decisions (2026-10-11)

1. **Undo is per principal.** Ctrl+Z undoes the latest transaction made by you **or by the agents working for you** (an agent acts on behalf of the person who started its session). The first Ctrl+Z while one of your agents runs pauses that session, then undoes, with the toast P3 describes. Collaborators (phase 5) are separate principals with their own history. Contract: undo stacks keyed by principal; `Actor::Agent` gains `on_behalf_of` (batched with the other contract changes).
2. **The Build Theatre is a mode of every workspace, not a tenth tab:**
   - a panel docked in the current workspace (right side by default)
   - `F` expands it to the full window, and it can pop out to a second monitor
   - follow mode keeps the agent's work in view
   - the violet presence dot on the workspace tab stays
3. **Keep the gold accent.** In the light theme, `warn` moves to a hue that stays distinct from gold for deutan vision: re-measure it in `design-system.md` §2.3, and keep icon plus word on every status.
4. **The built-in assistant ships in v1.0** (spec §12), with your own API key or a local model. It's phase 3 work. External agents over MCP need none of it.
5. **Go Live:** a two-step confirm on the first start of a session, then a single confirm with a visible armed state. An agent can never go live without a per-session `broadcast` grant from a person.
6. **Docking library:** `egui_tiles` unless a spike shows a blocker.
7. **Fonts and icons:** licence rows added to `docs/licensing/register.md`. Instrument Sans, Bricolage Grotesque, JetBrains Mono and Noto Sans CJK are OFL-1.1; `egui-phosphor` and Phosphor icons are MIT. The original sample character is Mira.
