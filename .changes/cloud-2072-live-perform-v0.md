# omuzaki-stage: the kit character performs live from a chosen camera (#2072)

- `perform::live::LiveStage` runs a live frame: it swaps in the source the input posted, services face variants, advances the performer and ticks the stage with the step's pose and channels, then feeds the renderer's report to `omuzaki-budget`'s `Scheduler`. It renders only when a step ran, so the result is deterministic in simulation time (#306, #314, #821).
- `perform::frame::PerformFrame` is the glue from the perform loop to the frame loop. A frame's `dt` covers every step since the last frame.
- `perform::input`: `InputHost` and `LiveInput` start and stop a `Tracker` on the bound camera, and hand frame sources to the perform thread through `SourceSlot`, which never frees on that thread. `input.source` and `input.camera` are Machine settings.
- The `input.*` ops are `input.select`, `input.bind_camera` (person only), `input.preview`, `input.request_camera` (person only) and `input.state`. Each edit answers its inverse call for undo (#301).
- The character's expressions are installed for the triggers when the live stage starts (#2088).
- `Performer::set_source` returns the old source, and `Performer::rest` returns the rest face.
- `Stage::set_quality`: `LiveStage` applies the scheduler's quality to the next frame. A stage on `StageClock::live()` numbers its frames by submission (pause, redraw and restart keep `FrameInfo::index` rising) (#821).
- `Stage::set_scene` and `commit_scene` take a resolved scene through `scene::apply` without allocating, reserve the lights when the stage is made, and put the subject member's root above each frame's root. `LiveStage::scenes` is the newest-wins mailbox the frame thread takes from once per frame; `owed` says what the scene still owes the renderer (#2142).
- Triggers: `trigger.bind` checks the expression and binds under one lock (`PerformHost::bind_trigger_checked`), and its dry run predicts the same `NotFound` (#2089). The stored undo and redo of a bind set the new `restore` argument, so they work while an expression is missing. `trigger.list` marks both the incoming and the fading-out expression active during a switch (#2090). Keys compare by Unicode case folding: Σ, σ and ς are one key, as are ß and SS (#2165).
- Review round: the source hand-off between the ops and the perform thread is lock-free (two atomic cell pointers; the perform thread neither locks, allocates nor frees); the stage shows the performer's own time, through catch-up frames and restarts (`FrameInput::time`); a resume from pause rebases the performer's clock (`PerformControl::rebase`); the scheduler's quality applies from the first frame; the owed scene work lives on the `Stage` and ends when committed; moving only the subject keeps the stage's own scene (`Stage::set_subject_root`); a variant swap installs the new face's expressions for the triggers (`Stage::revision`); a camera that will not open changes nothing; undoing an unbind or a change of source brings the preview back (`resume_preview`); keys fold as Unicode case folding does (`ı` is not `I`; `ẞ` is `ß`); a binding that takes a fading slot is not listed active.
