# omuzaki-camera-mf: the Windows camera

- New crate `omuzaki-camera-mf`: `MfCamera` implements the `Camera` trait on Media Foundation with an asynchronous source reader, so `next_frame` honours its timeout and capture keeps running between calls (the newest frame wins). It hands over raw NV12, YUY2, MJPG and RGB32 frames with the real row pitch, checked against the buffer's real allocation, follows a camera that changes its media type, and numbers frames from their capture times so skipped frames show as gaps. Mode choice, frame bounds, the sequence and the lock-free timed hand-off are shared code that builds and tests on every platform (#313).
